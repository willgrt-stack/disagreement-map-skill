# 表达示例

以下用于校准语言和判断方式，不是待套用的事实结论。示例均为材料内讨论，未进行新的事实检索。

## 有潜台词，但不能替人确定本意

给定观点：一方说“环境再差也有人赚钱，别只顾着抱怨”；另一方说“环境不好，赚钱就难”。

合适的回答：

> 这两句话可以同时成立：环境会影响赚钱的难度，人也仍然需要想办法。
>
> 前一句可以理解为在劝人行动：环境再差，生活还得继续，能做的事情要继续做。后一句是在解释困难：如果客户的钱少了、订单少了，同样的生意就可能更难做。一个人在说“再难怎么办”，另一个人在说“为什么变难”。
>
> 不过，如果前一个人坚持的是“环境对收入完全没有影响”，那就是另一个需要查证的主张，不能靠有人成功就证明它。至于环境是否真的变差、影响了哪些人，还要看具体时期和行业的数据。

为什么这样写：开头有判断；潜台词使用“可以理解为”；明确区分“别只抱怨”与“完全无影响”，没有替原话换立场。

## 确实在争事实，就直接判断

虚构材料：商家说某课程“对所有人都有效”，依据是20位自愿回访问卷的学员；反对者说“商家研究一律不能信”。

合适的回答：

> 这份材料不能证明课程对所有人都有效，但也不能因为是商家做的，就直接说它全是假的。
>
> 关键在于，这20个人为什么回来填问卷，其他学员怎么样，以及不参加课程的人有没有类似变化。现在这些信息都没有，所以只能知道这批受访者怎么说，还判断不了课程本身带来了多大效果。
>
> 真要判断值不值得相信，应看调查怎么做、有没有合适的比较，以及其他人能否得到类似结果。

为什么这样写：没有把同一事实上的冲突包装成“其实在谈不同问题”，也没有把商业关联当成真伪开关。

## 词语替换

| 内部分析用语 | 面向读者的说法 |
| --- | --- |
| 隐含前提 | 这句话要成立，得先满足一个条件…… |
| 推理桥不足 | 这个事实还推不出那个结论。 |
| 群体与个体层级混淆 | 一群人更难，不等于每个人都做不到。 |
| 价值判断与事实判断混用 | 他在劝你怎么做，但这还不能证明事情本来怎样。 |
| 外推边界 | 这项研究看的是这类人，换一类人不一定一样。 |

只在这些说法有助于理解时使用；不要让替换表变成另一套固定套话。
